Wyjaśnialny audyt techniczny WordPressa i WooCommerce. Wyłącznie do odczytu — pokazuje problem i zalecenie, ale niczego nie zmienia.

== Description ==

Sprawdza wersję PHP, HTTPS, ustawienia debugowania, widoczność w wyszukiwarkach, strukturę odnośników, rozmiar autoładowanych opcji, rewizje, transienty, limit pamięci, zaległości cron i nieaktywne wtyczki.

= Tylko do odczytu =

Ta wtyczka nie ma żadnej funkcji naprawczej. Nie usuwa rewizji, nie czyści transientów i nie uruchamia OPTIMIZE TABLE. Każde zalecenie jest opisane tak, żebyś mógł zdecydować sam — również o tym, czy najpierw zrobić kopię zapasową.

= Wynik punktowy =

Wynik służy wyłącznie do porównywania kolejnych skanów. Wysoki wynik nie oznacza, że witryna jest bezpieczna.

== Installation ==

1. Wgraj wtyczkę i aktywuj ją.
2. Wejdź w Narzędzia → WP Doctor.
