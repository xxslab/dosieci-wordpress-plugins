Tłumaczenie tytułów i opisów produktów przez DeepL na Twoim własnym kluczu API (BYOK). Zawsze z podglądem przed zapisem.

== Description ==

Tłumaczy pojedyncze pole wybranego wpisu lub produktu na jeden z 25 języków obsługiwanych przez DeepL.

= BYOK =

Korzysta z Twojego własnego klucza DeepL i Twojego limitu znaków. Zapytanie idzie bezpośrednio z tej witryny do DeepL — nie przez serwery DoSieci. Klucze Free (kończące się na „:fx”) i Pro są rozpoznawane automatycznie.

= Zawsze podgląd =

Zobaczysz wersję przed i po zanim cokolwiek zostanie zapisane. Po zapisaniu poprzednia treść pozostaje dostępna w standardowych rewizjach wpisu WordPressa.

= Zakres wersji darmowej =

Jedno pole, jeden wpis, jeden język na raz. Brak trybu masowego.

== Installation ==

1. Wgraj wtyczkę i aktywuj ją.
2. Wejdź w Narzędzia → Translator i zapisz swój klucz DeepL.
