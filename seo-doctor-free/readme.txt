Audyt SEO wpisów i produktów plus opcjonalne podpowiedzi AI na Twoim własnym kluczu API (BYOK). Tylko do odczytu.

== Description ==

Sprawdza tytuł, meta opis, długość treści, teksty alternatywne obrazków i slug wybranego wpisu lub produktu — i tłumaczy, co konkretnie jest nie tak.

= Współpracuje, nie zastępuje =

Wtyczka nie nadpisuje tytułów, canonicali, sitemapy ani schema. Nie ma nawet kodu, który by to potrafił. Dzięki temu nie wchodzi w konflikt z Yoast, Rank Math, AIOSEO ani SEOPress.

= BYOK =

Podpowiedzi AI korzystają z Twojego własnego klucza OpenAI i Twojego rozliczenia. Zapytanie idzie bezpośrednio z tej witryny do dostawcy — nie przez serwery DoSieci. Klucz nigdy nie jest wyświetlany w całości ani zapisywany w logach.

= Propozycje, nie automat =

Wygenerowane metadane są pokazywane do skopiowania. Wtyczka niczego nie zapisuje za Ciebie, a prompt jawnie zabrania modelowi wymyślania cech produktu, których nie ma w treści.

== Installation ==

1. Wgraj wtyczkę i aktywuj ją.
2. Wejdź w Narzędzia → SEO Doctor. Klucz API jest opcjonalny — sam audyt działa bez niego.
