Połączenie z eBay na Twoich własnych danych aplikacji (BYOK). Wersja darmowa jest wyłącznie do odczytu. Domyślnie Sandbox.

== Description ==

Sprawdza połączenie z eBay i pozwala przeglądać oferty bezpośrednio z wp-admina, korzystając z Twojego własnego App ID i Cert ID.

= BYOK =

Zapytania idą bezpośrednio z Twojej witryny do eBay. Nie przechodzą przez serwery DoSieci i nie wymagają subskrypcji.

= Tylko do odczytu =

Ta wersja nie wystawia ofert, nie importuje zamówień i nie zmienia stanów magazynowych. Klient API nie zawiera ani jednej metody zapisującej do eBay.

= Sandbox domyślnie =

Środowisko produkcyjne trzeba włączyć świadomie, osobnym przełącznikiem.

== Installation ==

1. Wgraj wtyczkę i aktywuj ją.
2. Wejdź w Narzędzia → eBay Connector i wprowadź App ID oraz Cert ID.
