Bezpieczna migracja adresów URL: podgląd zmian, skaner kolizji i przekierowania 301 bez łańcuchów i pętli.

== Description ==

Generuje czytelne adresy URL z tytułów wpisów i produktów — ale nigdy nie zmienia niczego bez Twojej akceptacji.

= Podgląd przed zmianą =

Najpierw widzisz pełną listę proponowanych zmian wraz z wykrytymi problemami. Dopiero potem decydujesz.

= Skaner kolizji =

Wykrywa i blokuje: slugi zarezerwowane przez WordPressa, dwa wpisy walczące o ten sam adres oraz kolizje z wpisami, których w ogóle nie zmieniasz.

= Przekierowania bez łańcuchów =

Po zmianie adresu stary URL przekierowuje kodem 301 na nowy. Jeśli adres zmieni się ponownie, przekierowanie jest spłaszczane — nigdy nie powstaje łańcuch ani pętla.

== Installation ==

1. Wgraj wtyczkę i aktywuj ją.
2. Wejdź w Narzędzia → Clean URLs i uruchom podgląd.
